# State Alchemists

We are State Alchemists.

We focus on building automation tools for software developers.

We believe good tools increase productivity and transform how people work.

# What We Create

- [Zrb](https://github.com/state-alchemists/zrb): Zrb is a task runner and CLI utility. It helps you write, generate, and run your tasks with ease, from a single task to a whole pipeline.
- [Zrb-Avatar](https://github.com/state-alchemists/zrb-avatar): Zrb-Avatar gives the agent a face. A 3D character in a small, see-through, always-on-top window: she stands on your desktop, shows what the agent is doing, speaks its answer, and can be dragged to any corner of the screen.

Zrb runs the tasks. Zrb-Avatar gives the agent that runs them a face, in a window that passes every click through to whatever is behind her.
